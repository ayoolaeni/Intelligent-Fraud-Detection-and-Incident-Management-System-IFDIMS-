# IFDIMS User Acceptance Test Questionnaire

Rate each statement on a 5-point Likert scale: **1 = strongly disagree, 2 =
disagree, 3 = neutral, 4 = agree, 5 = strongly agree**.

Column IDs (`Q1`...`Q12`) are used by `scripts/uat_summary.py` when
summarising responses collected in a spreadsheet; keep them attached to
each statement if you adapt this questionnaire for a live session.

## Usefulness

1. (`Q1`) IFDIMS helps me catch fraudulent transactions I would otherwise miss.
2. (`Q2`) The risk bands (low/medium/high) match my own judgement of how risky a transaction is.
3. (`Q3`) I would recommend using this system in my day-to-day work.

## Ease of use

4. (`Q4`) I can find the information I need on each screen without confusion.
5. (`Q5`) The alert queue and case list are easy to filter and search.
6. (`Q6`) The actions available to me on a case are clear and easy to use.

## Clarity of explanations

7. (`Q7`) The listed factors (SHAP explanations) help me understand why a transaction was flagged.
8. (`Q8`) The plain-English descriptions next to each factor are clear.
9. (`Q9`) I trust the system's explanation enough to act on it quickly.

## Support for case handling

10. (`Q10`) The case workflow (assign, investigate, escalate, resolve, close) matches how my team actually works.
11. (`Q11`) SLA countdowns and escalations help me prioritise my work.
12. (`Q12`) Notes, attachments and the audit history give me enough context to pick up a case from a colleague.

## Open questions

- What did you like most about the system?
- What was the most confusing or frustrating part?
- What one feature would you add or change?
